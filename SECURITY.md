# Security policy

## Reporting a vulnerability

Report vulnerabilities privately through GitHub security advisories:

<https://github.com/smoothvr/grok-bot-home-assistant-ui/security/advisories/new>

Do not open a public issue for a security report. This project does not accept reports by email or by phone.

The maintainer is [@smoothvr](https://github.com/smoothvr).

## What to leave out

The Home Assistant token stays in the browser's local storage on the tablet. Do not include tokens, local network addresses, or account details in a report, an issue, or a commit.

## Supported versions

Security fixes land on the current `main` branch.
